先说结论：**自动压缩和 `/compact` 命令当前都没有启用**，只有两套「省空间」机制在运行，它们分别用于省略旧图片和截断过长的工具输出。下面逐项说明。

## 一、先分清：三件事经常被混在一起

| 机制 | 当前状态 | 作用时机 |
|---|---|---|
| **自动压缩** `compaction-basic` | ❌ 未加载 | 上下文压力超过阈值时自动把旧历史总结成摘要 |
| **手动压缩** `/compact` | ❌ 命令不存在 | 输入命令立刻压缩一次 |
| **工具输出剪枝** `tool-result-pruner` | ❌ 未加载 | 仅在压缩触发后才会运行；未触发压缩时它不会执行任何操作 |
| **图片省略** `image-offload` | ✅ 已启用 | 路由拒绝某张旧图时，把那张图永久改成文字占位符 |
| **会话 checkpoint** `session-checkpoint-policy` | ✅ 已启用 | 长会话的历史保存点，和压缩无关 |

核对依据：`compaction-basic`、`tool-result-pruner` 的配置条目在实时配置里都是 `inactive`（未激活），说明它们没有被加载；仓里 `compaction-basic`、`command-compact` 都是 `enabled: false`。

**所以你现在没有「摘要式压缩」，也没有 `/compact`。** 长对话要么由模型自己处理，要么靠图片省略来节省空间。

# @deepseek-ai/dsh-commands

[English](README.md) | 中文

## 概述

`dsh-commands` 让用户能在交互式 Harness UI 中运行 `/command [input]` 操作，且不会把命令或结果变成模型消息。命令可以展示输入提示、接受附件，并只针对一个 agent 生效，同时为其他 agent 保留同名的全局命令。每次通过准入的执行都会记录到接收 agent 的会话日志中，UI 则在模型历史之外渲染结算结果。它适合为 `dsh` CLI（命令行界面）或 Web 客户端提供直接面向用户的控制；无 UI 的演示与 ACP（Agent Client Protocol）自动化不提供此命令面。

# @deepseek-ai/dsh-agent-instructions

## 概述

`dsh-agent-instructions` 向 agent（智能体）提供来自用户全局文件和项目级文件的工作区指引；这些文件均与 `AGENTS.md` 兼容。它为第一次请求加载适用的指令链。它不会持续监视外部编辑：成功的文件系统操作会发现新适用的嵌套文件，并让后续变更或移除可见；恢复会话也会对账基线。`dsh-base` 默认启用此行为，profile 可以禁用。字节预算分别限制用户全局指令链与项目指令链：每条链内较宽泛的文件先被省略，最具体的文件最后被截断，空指令链不添加任何内容。
