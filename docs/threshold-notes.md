## 观察

### 1. 阈值语义

`pressureRatio` 是**上下文窗口占用比例**，不是绝对字符数：

```
触发条件 = 已用 token ÷ contextWindow ≥ pressureRatio
100 万 × 0.5 = 500,000 tokens
```

| 口径 | 数值 | 占窗口 |

即：不是没有可压内容，而是压力判定偏低导致未触发。

## 结论 / 待办

- [ ] `underPressure()` 改为优先采用提供方上报的 `inputTokens`（`contextPressure` 投影），启发式仅作兜底。
- [ ] 面板增加「真实压力 / 估算压力」双显示，避免用户误判。
- [ ] 复核 `keepLast` 对新会话首轮的影响（首轮大量历史都算「最近」）。
